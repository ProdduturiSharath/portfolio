## Overview
This is a modern, highly interactive, and fully responsive developer portfolio designed to showcase my experience as a Backend-leaning Full-Stack Engineer. It features a sleek glassmorphism design, smooth micro-animations, and a terminal-style hero section.

The architecture was recently pivoted to a **100% React-only** setup, eliminating the need for a dedicated Node.js backend to ensure lightning-fast global load times with zero cold starts.

## Features
- **Dynamic UI:** Built with React and styled beautifully with Tailwind CSS.
- **Serverless Contact Form:** Fully functional contact form integrated securely with [Formspree](https://formspree.io/).
- **Native Data:** Resume data and projects are statically bundled for instant rendering.
- **Responsive:** Looks great on desktops, tablets, and mobile devices.

## Local Development

If you'd like to run this project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/SharathChandra09/PersonalPortfolioV2.git
   cd PersonalPortfolioV2
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Set up Environment Variables:**
   Create a `.env` file in the root directory and add your Formspree ID:
   ```env
   VITE_FORMSPREE_FORM_ID=your_form_id_here
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```

5. **Build for production:**
   ```bash
   npm run build
   ```
